# Trailmark v2.4.1 发布审计

审计日期：2026-08-09
范围：应用、部署脚本、全部可达历史与标签、依赖、界面、图片、文档、Release 与 GitHub 设置。

## 结论

- 84 项测试、Python 编译、Bandit、pip-audit、前端语法、部署配置和 CI 门禁通过。
- 浏览器错误只以文本渲染；异常、URL 凭据、查询参数与事件信息均经过边界化脱敏。
- 桌面与移动界面、完整表格/筛选/主题/空态/异常态、深灰 `#17191d` 与 SVG/PNG/ICO 收藏图标已实际验证。
- 1280×720 合成界面图与 1280×640 社交封面不含真实订阅、节点、出口地址、账号、服务器或设备身份。
- Gitleaks 与 TruffleHog 对公开新鲜克隆的完整历史及全部标签均为 0。

## 历史清理

最终复扫发现三个测试函数名符合 Lob 测试密钥的形状，并发现一个专门验证“拒绝 URL 内嵌凭据”的保留示例。它们均为合成测试数据；为避免外部扫描告警，夹具及全部可达历史已重写。不可变 `v2.4.0` 标签永久退役，当前支持版本为 `v2.4.1`。

旧历史仅存在于 `资料/安全修复备份/` 的私有 bundle。公开分支、标签与普通全量克隆不再引用旧提交；平台可能保留不可变发布证明或旧 SHA 缓存，不能把 Git 重写描述为互联网物理抹除。
