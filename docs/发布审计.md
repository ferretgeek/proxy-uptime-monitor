# 2.4.0 发布审计

核验日期：2026-08-08

## 已验证范围

- 应用、脚本、测试、部署文件、中英文文档、截图、PNG/ICO 元数据与示例配置。
- Python 编译、84 项自动化测试、Shell 与 PowerShell 语法、桌面和 390×844
  移动视口、四套主题切换与持久化、控制台错误和横向溢出。
- 固定依赖树的已知漏洞，以及基于规则和熵值的秘密扫描。

## 静态安全复核

- 19 个 SQL 告警均来自查询常量、固定条件、白名单排序字段或按集合长度生成的
  `?` 占位符；所有值仍通过 SQLite 参数绑定传入，不存在用户值拼接。
- 5 个随机数告警只用于计划任务抖动，不参与凭据、令牌或其他安全决策。
- 外部进程统一使用参数数组并禁用 shell；可执行文件来自显式路径或系统 PATH，
  不执行订阅内容和界面输入。

## 发布结论

在上述核验范围内，没有发现真实凭据、私人身份、真实部署地址、私有主机或未解释
的疑似秘密。截图使用合成数据，PNG 不含文本元数据。Linux 实机安装仍由使用者在
自己的目标主机执行；项目提供可审查的 `systemd` 安装、卸载与健康检查脚本。
